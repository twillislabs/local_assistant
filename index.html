Indicator

      
Shows when it's listening, thinking and speaking: an LED, a light, or anything you can reach with a URL or a script. HAL's eye: dim red at rest, bright when attending.

      
      
      

        

          

          

          

        

        
LEDs from /sys/class/leds. Ones marked "needs permission" can't be switched by this user (on a Raspberry Pi, add a udev rule or run the root setup).

      

      

        

          

          

        

        
        
      

      

        
      

      
In the URL, body or command, {state} (off, idle, listening, thinking, speaking), {brightness} (0–100), {color} (#rrggbb) and {r} {g} {b} are filled in from the personality's light colours.

      

        
        
        
Wiring: pin → 220 Ω resistor → LED long leg; LED short leg → GND. The colour of each state is ignored (single LED); brightness 0 means off.

Shortcuts it has learned

      
Teach by talking or typing in Chat: "When I say sit height, set the standing desk to 25 percent",
        "Standing also means stand height", "Change sit height to 30 percent", "Forget sit height",
        "What have you learned?". A shortcut runs instantly when it's the point of what you say ("sit height",
        "desk to sit height"), not when the phrase just appears in a sentence.

Things it remembers

      
Facts for conversation, e.g. "Remember that my favorite color is green". Saying a corrected version updates the old one; "Forget that …" removes it. One per line here.

      
      

    

  


  
  

    

      
Tools

      
What the assistant can do besides talk. Requests that mention a tool go to the model with all installed tools; anything else is conversation. Each extra tool makes the cached prompt longer, and a small model does best with a few.

Conversation

      
Anything that isn't for a tool gets a short spoken reply. On this machine it runs on a second Ollama instance (http://127.0.0.1:11436) so chatting never slows down commands. A network server with a GPU can serve both.

Copy this assistant

      
Export the settings (tools, personalities, voice, model, network options) to set up another machine the same way. Without secrets, tokens, passwords and API keys are left out; enter them on the new machine. Wi-Fi passwords are never included.

      
      

        
        
        
        
      

      
From the command line: ./profile.sh export NAME writes profiles/NAME.json to commit to git; ./install.sh --profile profiles/NAME.json sets up a new machine with it.
