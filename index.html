Indicator light

      
An LED or light that shows when it's listening. HAL's eye: dim red at rest, bright when attending.

      
      
      

        
        
        
Wiring: pin → 220 Ω resistor → LED long leg; LED short leg → GND. The colour of each state is ignored (single LED); brightness 0 means off.

If you're connected through the setup hotspot, it switches off while the board tries this network. If it works, reconnect your device to your normal Wi-Fi and open http://unoq1.local. If it fails, the hotspot comes back in about a minute.

Setup hotspot

      
When the board has no Wi-Fi connection, it starts this hotspot so you can connect and set it up at http://10.42.0.1. It turns off once the board joins a network.
